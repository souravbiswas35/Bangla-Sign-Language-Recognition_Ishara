# Place your trained model files here

Copy the following files from your Google Drive
(`Working With Compressed Videos/Models/`) into this directory:

1. `Transformer_best.weights.h5`    (or `Transformer_full_model.keras`)
2. `GRU_best.weights.h5`            (or `GRU_full_model.keras`)
3. `LSTM_best.weights.h5`           (or `LSTM_full_model.keras`)
4. `feature_scaler.pkl`

The backend will automatically load whichever models it finds.
